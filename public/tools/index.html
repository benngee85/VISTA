How these tools work

Each tool asks one narrow operational question — what natural hazards are open right now, is a country's monitored airspace disrupted — and answers it from a maintained World Monitor API contract. Results are labelled with their source and retrieval time, unavailable data is reported as unavailable rather than zero, and independent signals are never combined into a single opaque threat score.

When to use them

Use these pages for a fast, shareable check before a trip, a shipment, or a market open; use the live dashboard when you need the full picture — map layers, alerts, news, and country briefs side by side. Hazard coverage is documented in natural disaster tracking; chokepoint scoring in the chokepoint methodology.
