Coverage boundary

Yemen (YE), Saudi Arabia (SA), Djibouti (DJ), Eritrea (ER). Events outside this list are not included in the live totals on this page.

How to read this tracker

Use these monthly country summaries as a bounded pulse, then inspect the dashboard for event-level context, map layers, and other independent signals. The figures are not forecasts and should not be interpreted as a complete casualty or incident ledger.

Scope source: shared/crawlable-crises.json. Live metrics: HAPI/HDX humanitarian conflict summaries from the UN OCHA Humanitarian API, served through the World Monitor API.
